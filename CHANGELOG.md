# Changelog

## 1.1.1 (v2)
- Window always appears on startup (fallback if the first paint never arrives); software rendering to avoid graphics-driver issues; startup log in `%APPDATA%\Graphite Scientific\startup.log`.
- Clicking the app again brings the existing window forward.

## 1.1.0 (v2 redesign)
- Realistic physical-calculator design: textured moulded body, recessed keypad faceplate, matte domed keys with side walls, raised display frame with glass, solar cells, satin cursor ring.
- Larger, clearer SHIFT (gold) and ALPHA (red) labels; fixed broken secondary labels.
- Distinct themes: Graphite (charcoal), Midnight (navy lacquer with champagne keys), Titanium (brushed silver).

## 1.0.0
- First release.
